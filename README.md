# FIRST PAGE — 바이브코딩 입문 교재용 예제

『비개발자를 위한 바이브코딩 입문』의 첫 웹 프로젝트를 위한 독립 실습 저장소입니다.

## 완성 예제

- https://yeoullab.com/vibe-demo
- https://yeoullab.com/vibe-demo/steps
- https://yeoullab.com/vibe-demo/check

## 학습 목표

이 예제에서는 코드를 외우기보다 다음을 직접 확인합니다.

- 실제 페이지 파일을 찾기
- 제목·문장·링크가 있는 위치 알아보기
- 반복되는 카드 데이터 찾기
- CSS가 화면 모양을 바꾸는 방식 확인하기
- 수정 전후 결과를 비교하기

## 파일 구조

```text
app/
  layout.tsx
  page.tsx
  globals.css
package.json
package-lock.json
tsconfig.json
next-env.d.ts
```

## 실행

```bash
npm ci
npm run dev
```

브라우저에서 안내된 로컬 주소를 열어 결과를 확인합니다.
